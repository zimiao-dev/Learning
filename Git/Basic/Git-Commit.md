# Git Commit

## 常用流程

```bash
git status

git add .

git commit -m "docs: update backtracking notes"

git push
```

---

## Commit 类型

| 类型 | 用途 |
|------|------|
| docs | 学习笔记 |
| feat | 新增内容 |
| refactor | 重构 |
| fix | 修正 |

---
