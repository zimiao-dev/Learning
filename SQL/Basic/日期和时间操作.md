# MySQL 常用日期操作

## 获取当前日期和时间

- **CURDATE()**：获取当前日期

- **CURTIME()**: 获取当前时间

- **Now()**: 获取当前日期和时间

- **CURRENT_TIMESTAMP()**: 获取当前时间戳

```SQL

--- 获取当前日期，结果示例：2026-08-06

SELECT CURATE(); 

--- 获取当前时间，结果示例：17:33:34

SELECT CURTIME();

--- 获取当前日期和时间，结果示例：2026-08-06 17:33:34

SELECT NOW();

--- 获取当前时间戳，结果示例：2026-08-06 17:33:34
SELECT CURRENT_TIMESTAMP();

```

---

## 日期和时间的提取

- **YEAR()**: 提取年份

- **MONTH()**: 提取月份

- **DAY()**: 提取日期

- **HOUR()**: 提取小时

- **MINUTE()**: 提取分钟

- **SECOND()**: 提取秒钟

```SQL

--- 提取年份，结果示例：2026

SELECT YEAR('2026-08-06 17:33:34');

--- 提取月份， 结果示例：8

SELECT MONTH('2026-08-06 17:33:34');

--- 提取日期， 结果示例：6

SELECT DAY('2026-08-06 17:33:34');

--- 提取小时，结果示例：17

SELECT HOUR('2026-08-06 17:33:34');

--- 提取分钟，结果示例：33

SELECT MINUTE('2026-08-06 17:33:34');

--- 提取秒钟，结果示例：34

SELECT SECOND('2026-08-06 17:33:34');

```

---

## 日期和时间的格式化

- **DATE_FORMAT()**: 格式化日期和时间

- **STR_TO_DATE()**: 字符串转化为日期

```SQL

--- 格式化日期和时间，结果示例：2026-08-06 17:33:34

SELECT DATE_FORMAT('2026/08/06 17:33:34','%Y-%m-%d %H:%i:%s');

--- 字符串转为日期，结果示例：2026-08-06 17:33:34

SELECT STR_TO_DATE('2026-08-06 17:33:34','%Y-%m-%d %H:%i:%s');

```

---


## 日期和时间的计算

- **DATE_ADD()**: 日期增加

- **DATE_SUB()**：日期减少

- **DATEDIFF()**: 计算两个日期差值

```SQL

--- 日期增加1天，结果示例：2026-08-07 17:33:34

SELECT DATE_ADD('2026-08-06 17:33:34', INTERVAL 1 DAY);

--- 日期减少1天，结果示例：2026-08-05 17:33:34

SELECT DATE_SUB('2026-08-06 17:33:34', INTERVAL 1 DAY);

--- 计算两个日期差值，结果示例：365

SELECT DATEDIFF('2026-08-06 17:33:34', '2025-08-06 17:33:34');

```
