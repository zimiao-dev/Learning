# MySQL 常用数据类型

MySQL 中常用数据类型包括：数值类型、日期与时间类型、字符串类型、JSON类型和空间类型

## 数值类型

- **整数**：
    - TINYINT（1字节）
    - SMALLINT（2字节）
    - MEDIUMINT（3字节）
    - INT/INTEGER（4字节）
    - BIGINT（8字节）
    > 可选 [UNSIGNED] 表示无符号

- **浮点数**：
    - FLOAT（4字节）
    - DOUBLE（8字节）

- **定点数**：
    - DECIMAL(M, D)
    > M 指定长度，D 指定小数位数，占用4字节

- **位类型**：
    - BIT(M)
    > M 范围 1~64

---

 ## 字符串类型

- **定长**：
    - CHAR(M)

- **变长**：
    - VARCHAR(M)

- **枚举**：
    - ENUM

---

## JSON类型

- JSON
> 存储JSON对象或数组
